# CEmmWaveMIMOsystems
This code package is used to reproduce the numerical results of article:

Ying Wang, Qiang Guo, Jianhong Xiang, Yu Zhong, [Beamspace channel estimation for millimeter-wave MIMO-FBMC systems with lens antenna arrays](https://doi.org/10.1016/j.dsp.2026.106189), [Digital Signal Processing](https://www.sciencedirect.com/science/article/pii/S1051200426003088?via%3Dihub), 2026,106189.
